# discover-scan 预注册规则（rules_version 0.1.0）

> 本文件是阈值与规则的**唯一出处**，与 `snapshot.RULES_VERSION` 同步。
> **改动规则必须同时 bump `RULES_VERSION` 并在此追加「修订记录」行**——
> 无记录改参会让历史快照无法归因（设计 §8-4）。
>
> 阈值均为**预注册草案**：回填数据（v0.2）到位后按季度聚合裁决调参，
> 裁决前不得凭主观改数。

## 一、透镜

### L1 横截面便宜（**命中门槛**）

| 项 | 定义 |
|---|---|
| 度量 | `EY = 100 / PE_TTM`（百分数）；`pe_grank` = 该 PE 在**全 A 正 PE 子总体**中的分位（0–1，越小越便宜）；`ind_rk / ind_n` = 行业内 PE 升序排名 / 该行业正 PE 只数 |
| 阈值 | `pe_grank ≤ 0.15` **且** `ind_rk / ind_n ≤ 0.25`（两条均**含边界**） |
| 分位口径 | `skills/lib/stats.percentile_rank_inclusive`（含 `<=`）÷ 100，**与 pulse 同口径** |
| 行业字段 | tushare `stock_basic.industry` |
| 证据地位 | 惯例 + 待回填裁决（估值因子在 A 股呈时变，不作实证结论宣称） |

**已知局限（预注册时声明，不构成改参理由）**：
`ind_rk/ind_n ≤ 0.25` 在 **n < 4** 的行业恒不成立（n=3 时最便宜者也是 1/3 ≈ 33%）——
即**小行业标的结构性地无法命中 L1**。这是公式的字面结果；是否放宽（如按绝对排名兜底）
列为反馈窗议题，裁决前维持原式。

### L3 定价-盈利 gap（**加分项，非门槛**）

| 子项 | 定义 | 记分 |
|---|---|---|
| 利差 | `gap = EY − (rf + 2pp)`，`rf` = 中国 10Y 国债收益率（百分点） | `gap > 0` 记 1 |
| 隐含增速 | `g_implied = 100 / PE_TTM`（payout=1）vs **预告净利增速上限** | `g_implied < 上限` 记 1 |

- v0.1 **不设 L3 门槛**：利差对低 PE 股近乎恒真，设门槛会退化为 L1 单透镜。
- 一致预期（`report_rc`）需 10000 分不可得 → v0 用**预告口径**并明示局限。
- `rf` 不可得 → 利差子项降级记 0，**须记 warning**。

### L4 市场语境（**不进规则**）

pulse `market_form` 快照，仅作报告头注记。观测标签非信号
（Kirby 2023：状态标签不蕴含收益可预测性）。

## 二、中过滤（硬闸门，四门，全部通过才进 L3 排序）

| # | 门 | 实现 |
|---|---|---|
| 1 | 市场 = 主板 + 创业板 + 科创板 | 默认**排除北交所**（`--with-bj` 可开） |
| 2 | 排除 ST / *ST / 退市整理 | 名称前缀 `ST`/`*ST` 或含「退市」 |
| 3 | 净利 ≥ 0 | tushare `fina_indicator.profit_dedt`（**扣非归母净利**——接口无原始 `netprofit` 列，故同比「归母净利」**更严格**） |
| 4 | ROE ≥ 8% | `fina_indicator.roe_yearly`（**年化**；接口无 `roe_ttm`） |

- 期次取「最近一期」：按 `end_date` 最大，同期多条取 `ann_date` 最新者（**必须去重**——
  实测接口对同 `end_date` 会返回重复行）。
- 降级三档（设计 §5）：`fina`（首选）→ `forecast`（预告口径 + ROE 下限降级为
  「股息率>0 或预告净利>0」）→ `skipped`（该项跳过并明示）。
  **`pass=None`（不可评估）绝不等于通过**。

## 三、排序与输出

1. 主键 `pe_grank` 升
2. 次键 `sum(gap_flags)` 降（0–2）
3. 三级键 `ey_pct` 降
4. **终极兜底 `ts_code` 升**（并列时保证同输入同输出）
5. 行业分散：同行业最多 3 只（`--per-industry` 可调）
6. 输出 Top N（默认 15）

每只附**理由行**（命中透镜 + 关键字段值，全部直引引擎字段）与下钻命令
`invest.py report <代码>`。
