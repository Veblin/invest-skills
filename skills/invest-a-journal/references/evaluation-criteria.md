# 评估细则 + 校准场景

> v0.2.1 参考文档。供 Claude 在评估时按需加载。

## 一、买入四维评估细则

### 1. 逻辑完整性（Logic）

| 子维度 | ✅ 通过条件 | ⚠️ 需改进 | ❌ 不通过 |
|--------|-----------|-----------|---------|
| 驱动逻辑 | 具体可验证的因果关系 | 方向对但笼统 | 模糊或循环论证 |
| 核心假设 | 可量化的前提条件 | 定性但合理 | 无假设或"会涨" |
| 错误条件 | 有明确触发阈值 + 覆盖主要风险 | 有但阈值模糊 | 无错误条件 |
| 假设-逻辑一致性 | 驱动逻辑和假设互相支撑 | 部分自洽 | 自相矛盾 |

### 2. 数据盲点（Blind Spots）

自动检查 8 项（基于 query_data + market_microstructure 输出）：

1. PE 分位：是否被提及？无 Tushare → 标注 "无历史分位"
2. 对冲工具：ETF → 查 hedge_coverage；个股 → 多数无对冲
3. 拥挤度：如果涉及科技/小盘 → 标注 "未查询"
4. 流动性：日成交额趋势
5. 宏观环境：PMI/LPR/VIX 是否支持假设
6. 杠杆水平：两融/流通市值 + 标签
7. 市场广度：涨跌比
8. 极端情绪：涨跌停比 + 跌停家数

每项缺失的数据 → 追加 blind_spot note。

### 3. 仓位匹配（Position Sizing）

| 检查项 | 方法 |
|--------|------|
| 波动率 × 仓位 | 年化波动率 × 仓位% ≈ 组合风险贡献。与用户声明的最大可接受损失对比 |
| 对冲调整 | 有对冲工具（coverage=high）→ 仓位弹性更大；无对冲（coverage=none）→ 裸多头风险 |
| 名义 vs 可退出 | 跌停 >50 家 → 名义仓位 ≠ 可退出仓位 |

输出格式：陈述事实，追问矛盾，不给 "建议 ≤X%"。

### 4. 风险收益比（Risk/Reward）

- 下方空间估算：PE 回归中位数 + 盈利下行 → 价格区间
- 上方空间估算：基于用户假设的盈利路径 → 价格区间
- 非对称性判断：下方 > 上方 → 赚小钱冒大险

#### 4.1 失效条件预设（R-C02 必填）

**本节字段为必填**：写下「什么观察出现 = 假设证伪 → 启动重评估」。它是处置效应
的疫苗——**在入场时**把证伪条件写死，避免事后用价格涨跌反推理由。

| 要素 | 要求 |
|---|---|
| 观测项 | 可观测的**客观量**（价格/估值分位/财务指标/事件），不得写「基本面恶化」这类不可证伪表述 |
| 阈值 | 具体数值或区间；带口径（收益率/价格、窗口起止） |
| 数据来源 | 引擎字段名或 `[来源: Python calc: formula]`（P0：数字须可复算） |
| 复核时点 | 何时回看（季报后 / 月末 / 触达即看），与 scenario-plans 的「点位版本化」同构 |

写法示例（结构演示，非个股建议）：

```
失效条件预设：
- 观测项：{指标} 连续 2 个报告期 {方向} ｜阈值 {数值}{口径} ｜
  来源 {引擎字段名} ｜复核时点：{下一个报告期披露后}
- 点位版本化：{点位}（{date} 快照；失效追踪见 references/scenario-plans.md）
```

**不输出止损百分比建议**（LAW 6）：本字段只回答「哪个假设被证伪、何时重评估」，
不回答「跌到 X% 就卖」。

#### 4.2 止损知识框（文献注记，含条件限定）

> 以下为**知识性参考**，用于理解止损的行为学定位；**不构成任何参数建议**。

- **止损是行为疫苗，不是收益增强器**：其价值在于约束损失厌恶下的拖延，
  而非提高期望收益。
- **机械止损在均值回归（震荡）市有害**：Kaminski & Lo (2014, *Journal of
  Financial Markets*) —— 随机游走价格下，0/1 止损**必然降低**期望收益；
  只有存在动量时止损才可能增值（条件依赖，非普适）。
- **宽幅优于紧幅**：Dolvin & Foltice (2023, *Journal of Beta Investment
  Strategies* 14(1)) —— 低阈值紧止损显著降低超额收益，1.0–1.5 个标准差的
  宽幅设置显著更优，且可对冲处置效应。
- **条件限定**：上述结论均有市场/样本条件；A 股直接证据有限，引用须带
  市场与样本期注记（见 hypothesis-registry C15）。

## 二、卖出四维评估细则（v0.2.6 修正：与 SKILL.md 对齐，原三维缺参考点独立性核对）

### 1. 一致性（Consistency）

- 对比入场 PE/价格 vs 当前 PE/价格
- 当初的错误条件触发了吗？
- 条件未触发却要卖出 → 追问理由

### 2. 情绪检测（Emotion Check）

- 卖出是否发生在连续大跌后（>15%/5日）→ 恐慌性割肉风险
- 卖出理由中是否有情绪词（"害怕""受不了""感觉"）
- 涨跌比 <0.4 + 跌停 >50 → 大概率恐慌

### 3. 参考点独立性核对（Reference-Point Check）

- 本次卖出理由是否包含：浮盈目标 / 回本心理 / 亏损不甘 / 成本价锚定？（任一为是 → ⚠️ 参考点依赖，请改述为独立依据；实证锚 Kahneman & Tversky 1979、Odean 1998）
- 关键问题："如果这笔交易不是你的持仓，你还会做这个决定吗？"
- 决策独立依据：{逻辑失效 / 估值触发 / 信号反转 / 资金面变化 / 其他}

### 4. 机会成本（Opportunity Cost）

- 钱出来后去哪？持币还是换仓？
- 两融/市值趋势：去杠杆 → 持币观望可能更合理；冰点 → 可能错过反弹

## 三、校准场景

### 场景 1：中证 2000 ETF 无对冲高仓位（买入）

**用户方案**：买入 563300 中证 2000 ETF，仓位 8%，驱动逻辑 "小盘因子均值回归"，最大损失 10%。

**数据假设**：PE 38.5x（csindex），折价 -0.5%，AUM 15 亿，无对冲工具，年化波动率 31.5%，涨跌比 1.2。

**期望评估结果**：
- 逻辑: ⚠️（"均值回归" 从哪里回归？无具体锚点）
- 盲点: ❌（无对冲工具未被识别 + PE 分位可能偏高）
- 仓位: ❌（31.5% 波动 × 8% 仓位 × 无对冲 ≈ 组合风险过高）
- 风险收益: ⚠️（需计算具体下方空间）

**护栏追加**：若两融=去杠杆 → 追加 "流动性收紧" 盲点。

### 场景 2：ETF 溢价买入（ETF 买入）

**用户方案**：买入某 ETF，驱动逻辑 "行业景气反转"，未注意溢价。

**数据假设**：溢价 +3.2%，AUM 80 亿，有对冲。

**期望评估结果**：
- 盲点: ⚠️（溢价 3.2% → 买入成本偏高，需要时间消化溢价回归）
- etf_data.py flags 自动触发了 "⚠️ 溢价 3.2%" 标记
- 评估应追问 "你知道现在溢价 3.2% 吗？"

### 场景 3：7 月 V 型反弹中追涨（2026-07-21 基准案例）

**数据快照（7/21）**：
- 涨跌比 1.35（正常偏暖）
- 涨跌停比 9.8:1（极端亢奋）
- 两融/市值 ~2.7% 且连降（去杠杆中）

**护栏预期输出**：
- 规则 1 触发（去杠杆进行中）→ 追加盲点
- 规则 2 触发（涨跌停比 >5:1）→ 追加情绪回归风险
- 规则 3 不触发（广度正常）
- 两个盲点同时出现 → "去杠杆 + 亢奋 = 背离"

## 四、边界条件

### 数据完全不可得（全部 missing）

用户说 "我想买 XXX"，但 query_data 全部返回 missing。

→ 评估输出逻辑完整性基于用户文字（不依赖数据）；其他维度标注 "数据不可得，无法评估"；不阻止保存。

### 只有腾讯行情（无 Tushare）

PE 分位 = missing。标注 "当前 PE 36.5x（腾讯行情），无历史分位。建议后续通过 Tushare 补充分位数据。"

### 标的代码无效

直接告知用户 "未找到代码 XXX 的数据，请确认代码是否正确？"。不继续评估。

## 五、未行动观察复盘（R-C04）

**定位**：买入评估的**对照面**——记录「决定不行动」的时刻，供复盘时区分
「应做未做（action bias 反侧）」与「不应做却做（过度行动侧）」。

| 要素 | 要求 |
|---|---|
| 观察日 | 做出「不行动」决定之日（非事后回忆日） |
| 跳过理由 | **当时**的事实表述；不得用事后价格反推理由 |
| 跳过类型 | 未研究 / 研究后放弃 / 纪律约束 / 资金约束 |
| 观察时价格 | 回填的**基线**（无基线则回填无意义） |
| 后续价格事实 | 引擎可取的收盘价 + 涨跌幅；**不带方向判断** |
| 复盘归类 | 应做未做 / 不应做却做 / 待复核——**两个方向都要记** |

**措辞纪律**：写「跳过理由当时是/否成立」，**不写**「早该买」「幸亏没买」
——后者是用结果反推决策质量，属结果偏误（与 §4.1 失效条件预设同一纪律）。
