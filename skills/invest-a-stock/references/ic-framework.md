# 投资委员会（IC）决策框架

> v0.2.3 — 基于专业买方工作流的结构化决策模板

## 定位

投资委员会（Investment Committee）是买方投资流程的核心环节：分析师向委员会陈述投资建议，接受挑战性质询，最终形成通过/否决/暂缓的明确结论。本框架将这一流程标准化为可复用的决策模板。

**CLI 入口**：`invest.py ic SYMBOL`

## 决策五步

```
1. 案件陈述 → 2. 对抗性质询 → 3. 盈亏比分析 → 4. 判决 → 5. 追踪计划
```

## 决策规则

| 条件 | 判决 |
|------|:---:|
| 盈亏比 ≥ 2:1 + 质量检查无否决项 + 关键假设 ≥2 个可验证 | 通过 |
| 盈亏比 1:1 ~ 2:1 或 关键假设 <2 个可验证 | 灰色（需补充） |
| 盈亏比 < 1:1 或 质量检查有否决项 | 否决 |
