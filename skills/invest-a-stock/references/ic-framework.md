# 投资委员会（IC）决策框架

> v0.2.4 — 基于专业买方工作流的结构化决策模板

## 定位

投资委员会（Investment Committee）是买方投资流程的核心环节：分析师向委员会陈述投资建议，接受挑战性质询，最终形成通过/否决/暂缓的明确结论。本框架将这一流程标准化为可复用的决策模板。

**CLI 入口**：`invest.py ic SYMBOL`

## 决策五步

```
1. 案件陈述 → 2. 对抗性质询 → 3. 盈亏比分析 → 4. 判决 → 5. 追踪计划
```

## 两问触发器（极简门槛）

> R9 新增 — 对抗性质询前的**第一道极简门槛**。在「1. 案件陈述」之后、「2. 对抗性质询」之前执行。
> 两问不求穷尽，只求阻断最危险的两种错误：不看大盘买个股、周期高点当成长买。
> 任一问给出否定信号不直接否决案件，但必须成为对抗性质询的优先挑战项。

### 第一问：宽基估值分位？

宽基指数当前 PE 分位是多少？当前市场整体处于历史什么位置？

| # | 问题 | 数据源 | 记录 |
|---|------|--------|------|
| 1a | 沪深300 当前 PE 分位（近 5-10 年） | 指数 PE 引擎 | 偏高（>80%）/ 中性 / 偏低（<20%） |
| 1b | 中证500 / 创业板当前 PE 分位 | 指数 PE 引擎 | 偏高（>80%）/ 中性 / 偏低（<20%） |

- 宽基分位偏高 → 案件陈述须说明为何逆势（对抗性质询第一优先项）
- 宽基分位偏低 / 中性 → 通过门槛，进入第二问

### 第二问：还相信周期吗？（周期标的自查）

仅对周期标的（或盈利与行业周期高度相关的标的）执行。自查：**若盈利高点已过，原假设还成立吗？**

| # | 自查项 | 判定 |
|---|--------|------|
| 2a | 当前盈利处于周期什么位置？（上行 / 顶部 / 下行） | 上行 / 顶部 / 下行 / 无法判定 |
| 2b | 原假设的盈利路径是否建立在"周期持续或反转"之上？ | 是 / 否 |
| 2c | 若盈利高点已过，估值倍数还能维持吗？（周期高点低 PE 陷阱） | 能 / 不能 / 无法判定 |

- 2c 判定为「不能」或「无法判定」→ 标注"周期假设失效风险"，列为对抗性质询优先挑战项
- 任一自查项无法回答 → 标注"待补"，不得静默跳过

> 两问均为极简门槛：输出记入 IC 备忘录（案件陈述与对抗性质询之间），
> 不替代 2-4 步的完整质询流程。

## 决策规则

| 条件 | 判决 |
|------|:---:|
| 盈亏比 ≥ 2:1 + 质量检查无否决项 + 关键假设 ≥2 个可验证 | 通过 |
| 盈亏比 1:1 ~ 2:1 或 关键假设 <2 个可验证 | 灰色（需补充） |
| 盈亏比 < 1:1 或 质量检查有否决项 | 否决 |
