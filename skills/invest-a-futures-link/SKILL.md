# invest-a-futures-link 商品期货→股票联动扫描

> **工具约束说明**：frontmatter 的 `allowed-tools` 是 Claude Code 约定；在 DSH 等不读取该字段的 harness 下不生效，实际可用工具由平台自身沙箱控制。本技能主体为本地数据采集与计算（Bash/Python），外盘对照时经 WebSearch 补充。

## 概述

对 `references/commodity_map.yaml` 的 **15 条产业链映射**（常识性产业逻辑，非统计筛选），取期货主力连续与映射股票近 45 个交易日收盘，输出三层对照：

| 判定 | 含义 |
|------|------|
| 共振↑/↓ | 期货与股票同向（20 日口径，不足回落 5 日） |
| 背离 | 期货与股票反向——**最有信息量**：或股票未定价、或期货预期先行、或该股另有主导逻辑 |
| 分化 | 一边动一边不动 |
| 共振(成本反向) | `cost_inverse` 链（期货为成本端），方向已取反 |

**背离 ≠ 套利信号**：背离可能持续数月（股票主导逻辑不同、传导滞后、成本占比低）。背离的价值是**提示去深研为什么**，不是直接交易信号。

## 数据源与口径

- 期货：`futures_main_sina`（新浪主力连续，2026-09-08 实测 SR0/AU0/SC0/RB0 等全通、含当日）
- 股票：`stock_zh_a_daily`（新浪日线，非东财——规避反爬）
- **外盘未接入**（ICE 原糖/LME/COMEX）：免费内盘源为新浪；外盘层按需 WebSearch 补充（如中粮糖业案例：ICE 原糖 8 月 +21.5% 时郑糖滞后——外盘-内盘背离本身是信息）
- 全部变化率/统计由 pandas 计算（P0），报告禁止二次加工

## 分析纪律

1. **映射表是核心资产**：`commodity_map.yaml` 收录的是「公认产业逻辑」链，不是统计相关。代码已固化（运行时名称解析依赖深交所接口，实测不可用，已弃用）；退市/重组/取数失败会输出警告行，须人工更新（与接口地图冒烟同一维护节奏）
2. **方向判定只是提示**：共振/背离后须追问——共振是基本面兑现还是情绪同步？背离是传导未至还是逻辑断裂？（`invest-a-stock` 深研跟进）
3. **成本反向链**（当前仅豆粕——海大集团/牧原为下游采购方）解读要反着想：期货大涨对下游是利润挤压，但市场有时按「通胀涨价传导」炒下游——此时代际差异本身是研究线索。尿素链（华鲁恒升/云天化）为生产商，是正向收入端，勿混淆（2026-09-08 review F5 修正）
4. **结合周期位置**：期货分位（距 N 年高低）决定背离的可信度——高位背离 vs 低位背离含义不同；分位计算需另跑 Python（本工具 v1 只给变化率）
