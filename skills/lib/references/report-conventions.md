## 1. 输出格式层叠规则

### 1.1 两层输出

所有分析报告采用两层输出：

| 层 | 位置 | 内容 |
|----|------|------|
| **简报** | Claude 对话内直接输出 | 完整判断（结论+逻辑链+数据+风险），不依赖 .md 即可理解 |
| **详细文档** | `reports/{symbol}-{name}/{YYYY-MM-DD-HH-MM-SS}.md` | 完整备忘录 + 参考文献 + 所有数据来源 |

**简报铁律**（D4／原 LAW 17 — 金字塔结构）：
- 首屏必须有核心结论和逻辑链（数据→推理→判断）
- 标题传递信息量（完整判断句，禁止名词短语）
- 每个分析段落第一句是加粗主旨句
- 看摘要等于看全文：简报本身是完整判断，.md 是详细论证

### 1.2 报告文件命名

```
格式: reports/{symbol}-{name}/{YYYY-MM-DD-HH-MM-SS}.md
示例: reports/600176-中国巨石/2026-07-27-14-30-00.md
      reports/588000-科创50ETF/2026-07-27-14-30-00.md
```

**规则**：
- `{symbol}` = 6 位代码
- `{name}` = 证券简称（如 `中国巨石`、`科创50ETF`）
- `{YYYY-MM-DD-HH-MM-SS}` = 报告生成时的**实际北京时间**
- **写入文件前必须获取当前实际时间**（`TZ='Asia/Shanghai' date '+%Y-%m-%d-%H-%M-%S'`），禁止使用硬编码时间戳或不包含时分秒的近似值
- 文件名中的区分符为 `-`（连字符），不是 `_` 或空格

### 1.3 交互模式（产出前先聚焦）

skill 任务**产出长文档前**，先收集用户关注维度再裁剪输出（AskUserQuestion 若可用，否则对话提问）：

- 收集项：关注维度（可多选）、持有期、输出形态（完整/简报/深挖）
- 首轮给出默认产出的同时，立即进入聚焦轮（给出选项而非开放式提问）
- 用户明确指定了研究范围或流程固定时（如 `/invest-a-etf {代码}` 的标准流程），按指定流程执行，不强制提问

## 2. 硬约束（A1 / A2，原 LAW 6 / 6a）

### 2.1 绝对禁止

- 买卖建议、仓位建议（"建议买入/卖出/持有/加仓/减仓/止损/止盈"）
- 单一目标价（不标注假设前提的数字，如"目标价 XX 元"）

### 2.2 允许

- **多情景估值参考价**：乐观/中性/悲观情景，各附假设前提 + 概率权重 + "仅供参考，不构成投资建议"
- **交易结构分析**：条件性估值区间（基于情景锚定）、复核触发（假设失效触发）、操作纪律（研究流程规则）
  - 条件性估值区间 ≠ 买入建议
  - 假设失效触发 ≠ 止损指令
  - 条件性估值区间为 3 段参考（悲观锚区/中性-悲观区/中性锚区），必须标注情景锚定 + 假设前提 + 状态含义；不设触发条件/比例
  - v0.3.1 A5：原称「入场区间」，动作暗示强（易被读成交易触发器），已全链改称「条件性估值区间」

### 2.3 事实边界（禁止猜测 / 推断 / 幻觉）— 最高优先级

所有输出必须区分「事实」「分析」「未知」三态。**不知道就是不知道，不推断。**

**禁止行为**：

1. **禁止用推断填补数据缺口**：引擎/数据源没有的字段 → 写「未知/空白/不可得」；不写「应该是/推测为/大概是」
2. **禁止把「检索不到」断言为「不存在」**：检索覆盖不足 ≠ 数据不存在（可能被付费墙、权限、索引遮挡）。只能表述为「在可及范围内未检索到 / 公开不可独立验证」，**真伪未知不得选边站**（既不猜真也不猜假）
3. **禁止无来源的常识性推断**：行业知识、框架性陈述（如"周期股低 PE 是常态"）必须标注「框架性陈述（公开研究框架，非本次采集数据）」或「待验证」
4. **禁止替来源选边**：数据/来源冲突 → 并列报告冲突（A 口径 X vs B 口径 Y），不自行裁决谁对
5. **禁止主观概率冒充数据**：概率/情景权重为估计时显式标注「研究框架估计值（非统计频率）」
6. **禁止断言"无低估价值股/价值投资已失效"**：被低估标的存在与否是实证问题；对个人投资者是识别成本高于趋势投资的成本决策，不是市场无机会的结论（可表述为"个人识别成本高于机构，选择趋势路径"）

**强制行为**：

1. 每个数字必须带来源：引擎字段（`[来源: 字段名]`）/ Python 计算（`[来源: Python calc: formula]`）/ 可核实一手源（URL + 日期）
2. 无法核实的数字 → 三态判定：`可验证` / `公开不可独立验证`（付费墙等，注明原因）/ `未知`；后两者在正文标注
3. [分析] 段只能基于已列 [事实] 做逻辑推演，推演链逐步可追溯；分析结论 ≠ 事实，用条件句或概率表述
4. 计算必须由 Python 完成（P0：AI 禁止心算），输入数据本身存疑时在来源标注中注明「输入为媒体口径，未经官方验证」
5. **来源标注合法性（仅两种，无第三种）**：`[来源: 引擎字段名]` / `[来源: Python calc: formula]`。"Python calc 视角""口径源自引擎""聚合验证""Python 复算一致""自洽校验"等**未实跑字样一律禁止**——要么真跑 Python，要么删除该数字。加工组数字（两字段相除/相减/比例：倍数、百分点差、占比、点位差等二次加工）一律带公式标签：示例「流出量是同行 2.5 倍 [来源: Python calc: 2.33/0.93]」「落后 2.2 个百分点 [来源: Python calc: 8.84-6.67]」；比例化文字（"近六成"）同规则，须标注实际算式「占前十大近六成 [来源: Python calc: 23.19/39.75=58.3%]」（F2-2026-09-08）
6. **引擎清单 ≠ 聚合**：引擎输出的清单（big_move_days 数组、份额流 rows、事件表等）的计数（N 个/N 日）、比例、区间推导必须经 Python `len()`/聚合计算；LLM 目视清单得出的任何数字视为心算违规（R3）

7. **[分析] 块内事实性前提必须带来源（F1-2026-09-08）**：[分析] 引作推演基础的事实性断言（盈利状态、行业盈亏分布、政策/产业事实等）逐句带来源（引擎字段 / Python calc / 「检索摘要口径，出处待核实」），或标注「框架性陈述（公开研究框架，非本次采集数据）」「待验证」；**无标注的事实性前提不得作为推演基础**。证据强度标签只对其实际覆盖的数据依据负责——块内前提跨来源（引擎 + 检索摘要/推断）时须拆分标注或将标签收窄到最弱环节，禁止用单一标签背书混合来源块

8. **消息三态与类型标注（R-E01，v0.3.0 新增）**：引用消息 / 新闻 / 传闻时标**三态**——
   `事实`（有可核实一手源）/ `传言`（未证实）/ `证实`（官方来源确认）；可附**类型观察标注**
   （`注意力情绪型` / `基本面型`）。三条硬约束：
   - **标注不含方向语义**：只标状态与类型，**不预设「证实即反转 / 基本面型即漂移」**——该通用分类器
     未被文献验证（PEAD 针对盈余意外、涨停注意力研究针对特定价格限制事件，均不可直接推广）
   - **证实锚点须带官方来源**：**热度见顶 ≠ 证实**（与 event-calendar 的 `is_official_source` 同源）
   - 类型分流分类器落地前须先过**预注册 + 滚动样本外事件研究**（见
     [backtest_prereg/C8_预注册.md](backtest_prereg/C8_预注册.md)）；涨停/概念热度等**可先行单类验证**
   - lint：`wording-message-no-tristate`（引用传闻类表述而无三态标注 → warning）

**案例锚点（v0.2.3 新增，源自 2026-08-07 煤炭ETF 事故）**：
检索「CCI 指数 839 元/吨」公开渠道无结果 → 曾错误推断「数据不存在/可能是假的」。实际为官方付费订阅数据（付费墙遮挡）。正确输出应为：「839 元/吨：公开不可独立验证（付费订阅），真伪未知；可验证口径 CCTD 5500K（834→846→863）」。**检索不到 → 只允许说「未检索到」，不允许说「不存在」或「可能是假的」。**

### 2.4 点位证据等级与红线清单（v0.2.6 新增，来源：ABCD 调研 §1.3/§5.3）

**证据等级定义**（引用点位时必须带等级标签）：

| 等级 | 含义 | 典型点位 |
|------|------|----------|
| L1 | 顶刊/核心期刊实证或明确统计语义的描述性度量（可作参考系主标签） | 整数关口（指数级，Donaldson & Kim 1993；朱宁等 2017）；MA/BOLL 位置偏离（BLL 1992 状态度量定位） |
| L2 | 微观结构机制或权威机构支持（需机制注记） | 前高/前低（Osler 2000 订单聚集）；缺口带观察记录（JBEF 2020：回补非必然） |
| L3 | 市场习俗（仅展示 + 强制标签，不参与情景判定权重） | 斐波回撤位（Tsinaslanidis 2022：与随机位点无差异）；波浪位（不可证伪） |
| L4 | 明确反证（被引用时必须输出否定证据注记） | 波浪预测（Energy Policy 2018）；"缺口必回补"（JBEF 2020 方向相反） |

**禁止断言表**（红线，违反即违规）：

| 禁止断言 | 指标 | 违反证据 |
|----------|------|----------|
| "价格将回踩/测试 MA20" | MA | STW 1999（RC 校正后消失）；PBFJ 2024（中国样本外转负） |
| "触及 BOLL 上轨将回调" | BOLL | Taiwan 50 上轨应追势（Physica A 2020） |
| "缺口必然回补/将回补缺口" | GAP | JBEF 2020（缺口后沿缺口方向延续）；A 股一字板缺口结构性不回补 |
| "38.2% 回撤位有支撑/压力" | 斐波 | Tsinaslanidis 2022（与随机位点不可区分） |
| "X 浪回撤将止于 Y%" | 波浪 | 不可证伪（Energy Policy 2018） |
| "整数关口必然受阻/突破" | 关口 | 自我实现机制（Frankel & Froot 1990）——有效但非决定性，须概率化表述 |

**允许的表述形式**（红线外）：

- "当前价 X vs MA20 Y，偏离 +Z% [来源: engine]"
- "整数关口 4000 为市场关注位（中国实证：熊市效应最强）[证据: L1-2]"
- "缺口带 3983~4015 未回补已 N 日（记录性事实；回补非必然）[证据: L2]"
- 斐波/波浪位可与实证点位并列展示，但**必须带 L3 习俗标签**，不得与 L1/L2 点位同权重
- "回踩/量度目标/周线级别"等 C 级内容标注「实操统计，非学术」

#### 2.4.1 斐波/波浪否定注记模板（R-E02 强制）

**引用**黄金分割位、斐波回撤位、波浪位/浪型的**任何**行，必须同行附固定否定注记
（只带 L3 标签不够——标签可被读者忽略，注记才是显式否定证据）：

> 该点位属市场习俗（L3），无样本外盈利证据（Tsinaslanidis 2022 与随机位点无差异；
> 波浪不可证伪），仅作展示参照

- 模板措辞**逐字固定**，不得改写为等义短句（lint 以关键词豁免：见 §3.2 模式 #20/#21）
- 引用须带**快照日期 + 失效追踪**，与 [scenario-plans.md](scenario-plans.md) 的
  「点位版本化」同构：`{点位}（{date} 快照；失效追踪见 scenario-plans 点位版本化）`
- **不适用场景**：仅在「本报告不使用斐波/波浪」这类否定式说明中提及术语时无须注记
  （由 lint 的 `skip_if_pattern` 覆盖：含「不构成/风险提示」等否定语的行豁免）
- 强制理由：C6 裁决——斐波/波浪**无主流期刊检验**，箱体/三角仅「可机械识别、
  统计差异 ≠ 可盈利」；不给否定注记等于让习俗内容以实证面貌出现

## 3. 措辞规范

### 3.1 禁止词替换表

| 禁止 | 替换 | 适用场景 |
|------|------|---------|
| "估值崩溃风险" | "剧烈估值收缩风险：在 XXX 场景下，估值从 AAAx 收敛至 BBBx" | 风险模块 |
| "经典周期顶部信号" | "历史上周期股出现 X、Y 行为时，往往处于高景气周期顶部附近；当前行为模式与这些模式相似，但并非充分条件" | 动态驱动 |
| "股价也可能下跌 60-80%" | "若盈利路径不及 AAA 预测、且估值回到周期中枢 BBBx，则与当前市值相比，价格有 60-80% 的回调空间" | 风险模块 |
| "往往是估值峰值" | "在多次周期品历史走势中，盈利峰值与估值峰值出现时间高度重叠（案例：XXX），但并非必然规律" | 市场结构 |
| "往往伴随 20-30% 快速修正" | "在 AAA、BBB 等类似斜率的高涨中，随后 N 个月内出现 20-30% 回调（案例研究待补）" | 技术结构 |
| "极度高估"/"极度低估" | 不用形容词，改为 "PE 665x vs 同赛道平均 40x，溢价约 16 倍" | 估值段落 |
| "崩盘" | "剧烈回调"（后接条件描述） | 任何场景 |
| "大概率/很可能/可能是"（修饰未经证实的数据真伪） | "真伪未知：公开不可独立验证，未验证前保持未知" | 数据来源存疑时 |
| "推测为 X / 应该是 X"（填补数据缺口） | "X：未知（需核实），不推断" | 数据缺失时 |
| "止损提高收益"/"止损提高胜率" | "预设止损降低尾部风险与波动（Kaminski & Lo 2014），但可能牺牲期望收益；其价值在对抗'过久持亏'（行为矫正，Fischbacher et al. 2017）" | 止损话术 |
| "止损是最重要的纪律"（暗示收益增强） | 定位为"防呆风控"（行为矫正），不承诺收益 | 止损话术 |
| "全线创新高"（多国/多标的整体断言） | 逐项复算，输出「X 项中 Y 项成立」+ 每项当前值 vs 全序列最高值 + 最高值日期（C6） | 宏观/多标的对比 |
| "理论上无顶部"/"无价格顶部"/"长期方向不变" | 需求侧支撑与价格结论分离表述：如"央行结构性购金提供长期需求支撑，但金价高位后历史均值回归显著（Erb & Harvey 2013：1980-01 峰值 850 → 1999-07 谷底 252.80，-86.1%）"（C8） | 资产价格外推 |
| "基本面短期意义有限/不重要"、"不纠结个股短期基本面" | 带条件限定的方差归属表述："在高同步性板块 + 短窗口（日/周）+ 高波动市态下，收益方差由板块成分主导；基本面在中长期、低同步性个股、横截面定价与剧烈回调尾部中恢复意义"（C7） | 板块/个股分析 |
| 未标口径的"距前高 X%" | 强制标注口径（收益率 vs 价格）+ 窗口起止日："距前高 -10.07%（收益率口径，2025-11 至 2026-06 窗口）"（C10；两口径差异可达 67 倍） | 任何距前高/距区间高低点表述 |
| 传导链三环节等权表述（如"中东→美债→AI 融资→资产价格"） | 逐环节标注证据等级（A/B/C/D），最弱环节（C/D 级）不得作核心论证（C9） | 宏观传导论证 |
| 月频海外数据描述当期状况（英德法日 10Y 等） | 强制 staleness 标注：「截至 YYYY-MM，滞后约 N 个月」（E5/E2） | 月频/周频海外数据 |
| "收窄/放缓/企稳/回暖/改善/好转"（负面数据上下文，无配套数字） | 带方向性数字 + [来源: ...]："净流出收窄至 -12.3% [来源: …]"（R-A5） | 负面数据处理 |
| 仅正化表述（"情绪回暖""压力缓解"等对负面数据无量化呼应） | 负值 + 幅度 + 来源："净流出 -12.3 亿，较上月 +5.1 亿 [来源: …]"（R-A5） | 负面数据处理 |

### 3.2 已知违规模式

1. "当前处于左侧/右侧" — 违反 D3（原 LAW 16）。改为 "左侧特征更强：XXXX；右侧支撑：YYYY。综合概率：左偏（≈60% vs 40%）"
2. "建议买入/卖出/持有" — 违反 A1（原 LAW 6）
3. "目标价 XX 元"（不标注假设前提的单一数字） — 违反 A1（原 LAW 6）
4. 无来源的"往往/通常" — 违反 A4（原 LAW 3）。标注"待补"或转为案例
5. PE 分位数用于亏损标的 — 亏损期标的必须标注"仅作位置参考"
6. "极度高估/低估" — 必须用数值比较替换
7. "检索不到 → 推断数据不存在/可能是假的" — 违反 §2.3 事实边界。只能表述"在可及范围内未检索到/公开不可独立验证"
8. "涨到 X% 就卖"类浮盈目标卖出理由 — 提示按 Odean 1998 改述为逻辑失效条件（卖出评估场景）
9. 单用 K 线形态（连续上涨/突破均线）断言主线 — 违反主线资金流确认规则（A 股无动量，Chui et al. 2022）
10. 宣称"止损提高收益/胜率" — 无实证支持（Kaminski & Lo 2014：随机游走下止损必然降低期望收益）
11. "无低估价值股/价值投资已失效"类断言（C3）

12. "全线创新高/整体创新高/全部创新高"类多标的整体断言 — 未逐项复算（C6）。须对全量序列跑 Python `max` 复算，输出「X 项中 Y 项成立」+ 各自当前值/最高值/最高值日期（lint：`wording-macro-all-time-high`）
13. "理论上无顶部/无价格顶部/长期方向不变" — 需求侧机制与价格结论混为一谈（C8，史实证伪：1980-01 峰值 850 → 1999-07 谷底 252.80，-86.1%）。须需求侧支撑与价格结论分离表述（lint：`wording-macro-no-top`）
14. "基本面短期意义有限/不重要/不纠结个股短期基本面" — 收益方差归属结论被外推成定价与研究价值结论（C7）。须带条件限定："高同步性板块 + 短窗口（日/周）+ 高波动市态"下收益方差由板块成分主导；基本面在中长期、低同步性个股、横截面定价与剧烈回调尾部中恢复意义（lint：`wording-macro-fundamentals`）
15. 未标口径的"距前高 X%" — 收益率口径与价格口径差异可达 67 倍（C10，10.07/0.15=67.13）。必须标注口径（收益率 vs 价格）+ 窗口起止日（lint：`wording-macro-distance-no-criterion`）。标准表述模板：「距 2026-05-06 高点 -30.54%（价格口径（NAV 前复权），窗口 2025-08-25 起 252 交易日）」
16. 传导链三环节等权表述（"中东→美债→AI 融资→资产价格"类）— 未逐环节标注证据等级（C9；环节① A 级 Weber 2018 JFE / 环节② C/D 级 / 环节③ B/C 级，最弱环节不得作核心论证）。**强制机制**：lint 规则 `wording-macro-chain-evidence`（error 级）+ 第 2 层合规复检强制检查项，双保险
17. 月频海外数据描述当期状况（英德法日 10Y 等，滞后约 2.5 个月）— 未带 staleness 标注（E5/E2）。强制标注「截至 YYYY-MM，滞后约 N 个月」（lint：`wording-staleness-monthly-overseas`）
18. 报告内部 §N 交叉引用错位（"§N" 指向节不包含被引内容，如「装机同比大幅下滑（检索摘要口径，§10）」而 §10 无此内容）— 引用前核对指向节实际承载内容；§ 指针随文迁移同步（F4-2026-09-08）
19. [分析] 块内事实性前提无来源标注且被块尾证据强度标签背书（盈利状态/行业盈亏分布等断言）— 见 §2.3 强制 7（F1-2026-09-08）

### 3.3 负面信息淡化防规（v0.2.8 新增，R-A5）

负面指标（净流出/亏损/负增长/净减少/下滑/下跌/回撤/失血等）**禁止仅用正化表述描述**（"收窄/放缓/企稳/回暖/改善/好转"）而缺失方向性数字与来源——无量化的正化表述会丢失负面数据的幅度信息。

| 情形 | 正确做法 |
|------|---------|
| 负面数据仅正化表述 | 带方向性数字 + [来源: ...]："净流出收窄至 -12.3%（[来源: engine northbound]）" |
| 定性改善无量化 | 负值 + 幅度 + 来源："净流出 -12.3 亿，较上月 +5.1 亿 [来源: …]" |
| 数据缺失 | 三态标注「未获取到有效数据/公开不可独立验证」，不推断改善 |

lint：`wording-negative-softened-no-number`（error）／`wording-negative-softened-no-source`（warning）。

**证据边界注记**（deep-research 2026-08-29 §2.9/2.10）：
- Gong 2016（SSRN，**未同行评审**）：语调（正面化）与崩盘风险关联研究的早期路线——原文以"consistent with"表述，仅作佐证方向，**不构成因果结论**，不作本防规的唯一支撑。
- 王嘉鑫 2022（同行评审，中国 A 股样本）：正面化语调与崩盘风险关联显著——本防规的主要文献支撑。
- 工程规则独立性：本防规以「负面数据必须带方向性数字与来源」为数据完整性要求——**无论语调-风险学术结论是否成立**，负面数据丢失数值本身即违反 P0（数字须有引擎/Python 来源）。

### 3.4 SEC 简报可读性建议（软性，R-A7）

> **明示为建议而非硬规则**：以下各条是给简报/执行摘要的可读性偏好（参考 SEC Plain-Language 要求的精神），配合 R-A1 指标（`qc-report` 的可读性指标组：篇幅/长句占比/术语密度/结论四要素）使用，不触发 lint error，不作合规阻断。

| 建议 | 说明 |
|------|------|
| 短句优先 | 单句 ≤45 字（R-A1 长句阈值）；长句占比 >30% 时用 `qc-report` 提示后拆分 |
| 主动语态 | "市场回吐 X 亿" 优于 "X 亿被市场回吐"；"催化剂支线未兑现" 优于 "催化剂支线的兑现未发生" |

| 避免术语堆砌 | 工程/统计术语（LTTB、CSAD、口径敏感性）在简报中给出解释或在 `#refs` 追溯表锚定，不裸用名词 |
| 数字可计算 | 所有数字按 P0 纪律经引擎/Python 计算，与正文复用同一 `[来源: ...]` 标签 |

## 4. 分析合成框架

所有报告必须包含以下分析合成步骤。这不是 checklist — 是核心分析工作。

### 3.5 「从业者惯例」标注系统化（v0.3.0 新增，R-E03）

**固定模板（逐字，不得改写为等义短句）**：

```
[从业者惯例，非学术验证：{出处}]
```

**适用对象**：直播 / 社区 / 研报界流传但**无期刊证据**的表述，如
「缩量跌不动」「回踩低吸」「托底」「右稳左可」「必带止损」「电风扇」「洗盘」「吸筹」「出货」。

**三条硬约束**：

| # | 约束 | 理由 |
|---|---|---|
| 1 | **不得置于 `[事实]` 块** | 惯例型表述是观察框架，不是事实；放进 [事实] 块等于以事实面貌呈现未经检验的先验 |
| 2 | **不得与学术证据同权重** | 不得与带文献注记的实证结论并列论证（与 §2.4 的 L3 习俗标签同一纪律） |
| 3 | **模板逐字 + 填出处** | `{出处}` 填该说法的来源（直播/研报/社区）；出处不可考则写「出处不可考」而非省略标签 |

**lint**：无标注即出现 → `wording-practitioner-convention`（**warning**，提示补标注）；
出现在 `[事实]` 块 → `structure-convention-in-fact-block`（**error**，块级拦截）。

### 4.1 对抗性假设检验

对报告中最核心的判断假设，逐一找**可证伪条件**。

| 关键假设 | 可证伪条件 | 观测窗口 |
|----------|----------|:---:|
| "毛利率改善可持续" | 下季毛利率环比回落 >2pp | 下份季报 |
| "行业景气度上行" | 行业 PMI 连续 2 月回落 | 月度 |
| ... | ... | ... |

**硬约束**：
- ≥3 个关键假设，每个必须有可观测的证伪条件
- **攻击自己最核心的判断，不是边角料**
- 不可证伪的假设标注「不可验证，置信度降级」
- 观测窗口必须是具体时间或事件节点，不能是「待观察」

### 4.2 「致命一击」归纳

一句话回答：**如果这个分析错了，最可能是因为什么？**

> **{持有期} 的最大风险**：[X 条件]。若 [Y 可观测触发]，当前分析框架的 [Z 方向性判断] 失效。

**硬约束**：
- 必须是条件句（若…则…），不能是模糊的风险罗列
- 指向具体的、可观测的失效条件，不是"市场风险""政策风险"等标签
- 与对抗性假设检验中风险最高的假设呼应，但不重复

### 4.3 盲点检查

Final pass 自问三个问题：
1. 有什么重要变量完全没有被讨论？
2. 当前共识最可能忽略什么风险？
3. 如果一个月后回头看，今天最明显的盲点会是什么？

```
🔍 盲点发现:
- [盲点 1] — 当前: [未知/数据不可得/未覆盖]
- [盲点 2] — 当前: [未知/数据不可得/未覆盖]
```

**硬约束**：≥2 条盲点，不能为空集。无数据的盲点恰是最重要的盲点。

## 5. 证据强度标注（SOP-EV）

所有分析性段落遵循 [事实]→[分析] 结构，末尾附四维证据标签。

### 5.1 格式

```
[事实]
- 具体数据点 + 来源

[分析]
基于事实的逻辑推演

[证据强度: ✅ 强 🌐 多源 🕐 近30日 ✓✓ 跨源一致]
```

### 5.2 四维标注

| 维度 | 标签 | 含义 |
|------|------|------|
| **数据可靠性** | ✅ 强 / ⚠️ 中 / ❓ 弱 | 数据源质量 |
| **来源丰富度** | 🌐 多源 / 📡 单源 / 🔮 推测 | 来源数量 |
| **时效性** | 🕐 近 30 日 / 📅 近季度 / 🗄️ 滞后 >1 年 | 数据新鲜度 |
| **交叉验证** | ✓✓ 多源一致 / ✓✗ 源间有差异 / — 单源无验证 | 源间一致性 |

> 标签覆盖注（F1-2026-09-08）：四维标签评估的是该块**数据依据**，不是块内全部文字。事实性前提来自检索摘要/推断时，标签须拆分或收窄，不得用「✅ 强（csindex 一手）」标签覆盖含未核前提的分析块（见 §2.3 强制 7）。
>
> **标签语法（v0.3.1 round-5 收紧）**：方括号 SOP 标签必须是 ASCII `[证据强度: …]`（`:`/`：` 均可），**四个维度齐全、固定顺序、图标与注解一一配对**——强度 ✅ 强 / ⚠️ 中 / ❓ 弱；来源 🌐 多源 / 📡 单源 / 🔮 推测；时效 🕐 近 30 日 / 📅 近季度或报告期已注明 / 🗄️ 滞后 >1 年；交叉 ✓✓ / ✓✗ / —（注解可省但须配对）。**缺维度、重复维度、图标与注解矛盾（如 `🌐单源`、`🕐滞后 >1 年`）、标签内夹带文字/数字一律不合法**，不享受结构行豁免；其中的数字照常要求事实绑定。单维元数据（引擎卡片）用渲染器体例 `**证据强度：⚠️ 中**` 表达，与方括号四维标签分开。命名空间按括号配平识别（ASCII `[`、中文 `【`、全角 `［`，键与冒号前后可空白），非法标签/包装内部的 `[来源:]`/`[证据:]`/`[事实:]` 不是正文证据；合法标签之外的来源/事实绑定照常有效。解析规则唯一来源 `skills/lib/evidence_tags.py`。
>
> 时效档判定（v0.3.1 round-4 修订并撤回三轮「跨年/TTM/多年窗口 ⇒ 滞后>1 年」补充；round-5 补边界）：新鲜度按块内数据依据的**最新有效事实日期/报告期相对报告基准日**判定；**窗口跨度、序列长度与采集日期都不用于判档**，历史覆盖窗口须另行在正文注明；日期须与对应封存字段绑定（不得以采集日期冒充事实日期），未知时点如实声明未知。
>
> - 🕐 近 30 日：**0 ≤（基准日 − 最新有效日期）≤ 30 天**；**负年龄不接受**——晚于基准日的事实不是「过去 30 日」；
> - 📅 近季度：最新有效数据日期在报告基准日前**三个日历月内**（按日历月计、边界含，非固定 90 天；最近一期定期报告即属此档）；
> - 📅 报告期已注明（中性档，不宣称近季度）：最新有效数据日期逾一个季度且在一年以内，或块内为**混合期间/滚动窗口**（TTM、多年序列用于变动比较等）无法用单一日期概括，或**独立事件时点晚于行情基准日**（如公告窗口越界）——正文须逐项注明真正日期/期间与历史覆盖窗口，晚于基准日的事件须明确其独立时点且声明不用于解释其前的行情/财务读数；
> - 🗄️ 滞后 >1 年：最新有效数据日期在报告基准日前一年以上。
>
> 历史序列只用于变动比较、不改变新鲜度档：不得以最早样本判陈旧，也不得以采集日期充近 30 日；TTM 类块的**最新期与历史覆盖起点**须分别注明。来源丰富度与交叉验证须按**本块实际使用的来源**判定：仅当本块依据确含两个及以上来源（如同维度融合源、多维度交叉）才可标 🌐/✓✗。

### 5.3 结论段扫描与渲染器标签行（R2 / #36）

- **渲染器标签行不是断言**：渲染器按各宿主体例输出 `**[事实]**` / `**[分析]**` / `**证据等级：** {标签}` 标签行（字段非空才输出，体例随宿主而异）；R-A2（结论段逐行证据扫描）已精确豁免整行恰为纯标签者（标签后跟正文的行仍按断言扫）。作者**不要在 `facts_md`/`analysis_md` 里重复写**这三个标签。
- **结论段判定与扫描边界（R14，2026-10-05）**：标题族（主判断/主要结论/核心判断摘要/重要发现等，见 `report_qc._CONCLUSION_HEAD_RE`）所在节整节逐行扫证据标签；**段边界为「下一个同级或更高级标题」——更深子段（H3/H4）继续扫**，子标题包装不能成为扫描盲区（反例：`### 竞争解释` 注入无来源断言）。卡标题以「结论」开头不再必然触发误报，但推荐体例仍按 D4「标题即论点」写完整判断句（例：「当前价处近五年 45% 分位——三段参考区间与四项失效触发（结论与交易结构）」）。
- **表格断言（R14，round-7 收紧 / round-8 再收紧）**：结论段/事件分析段内的表行不整体豁免——真表头（有数据行时的首行）、分隔行、**全数据格**数据行（数值/日期/占位符）放行；**「短标签+数值」不再豁免**（round-8：短长度无法与 8 字内短断言区分，Codex `| 公司盈利持续改善 | 999 |` 反例）；**占位符（`—`/`N/A`）不作锚点**；**来源字符串不作整行/整表免审依据**——单元格内含 `[来源:]`/`[证据:]` 不再使该行按数据放行，**邻近（块外前后）的 `[来源:]` 不再给整表豁免**；混合行（含任何文字格）唯一豁免通路是行内 `[来源:]`（须为有效依据，事件段同 R13 判据）/`[证据: A–C]`/真实 `[事实: F…]`，嵌套在 `[证据强度: …]` 命名空间内的伪来源不构成证据。**渲染器固定结构表（事件时间线表）按逐字表头识别、数据行逐行结构核验**（round-8：日期格=YYYY-MM-DD、类型格∈taxonomy 标签或原始英文键、维度格∈taxonomy 维度词表或空、标题格非空；`| ... | ... | （另有 N 条事件未展示） | ... | ... |` 截断行同放行）——**表头身份不再构成整块豁免**（复制表头的断言注入不得借表种放行）；**行级结构豁免还须通过生产者身份绑定（2026-10-07 主线收尾）**：表块须紧跟渲染器固定来源尾注 `[来源: akshare stock_individual_notice_report / N 条事件；行指纹 sha256:<32hex>]`——数据行数与 N 一致（>15 条为 15 行+截断行），且尾注行指纹与报告实际数据行的规范串（`lib.events.event_table_fingerprint` / `report_qc._event_table_fingerprint`，每行 cell 去空白后以 `|` 连接、行间换行、sha256 前 32 hex）重算值一致——契约不符（复制块/复制尾注、行内增删、1:1 换标题）即退回普通断言行检查，fail-closed；**自由 analysis_md 的表格不得因复制生产者外形免证**。机器只检查来源与缺口纪律（有无绑定、绑定是否合法真实）与登记表结构词表/契约（含行指纹自洽），不判断表内文字（含标题格）的语义——重算指纹并整体伪造行集合属「连贯伪造生产者输出」，文本级检查无法区分（彻底闭合需 QC 直读封存 events 的协议，v0.3.2 候选）；该残留边界如实记录。
- **事件分析段（R13/R14，2026-10-05）**：`## 3a. 事件时间线`（含 v0.2 体例）整段（含子段）同走逐行证据扫描（`wording-event-analysis-evidence*`）。公告标题、类型分类与类型默认维度/持续性是**分类线索**，不是已核影响——未读公告原文时不得写影响判断（含「不改变盈利路径」「短期扰动」等否定式/持续性断言），应写「影响未知/不纳入经营结论」；取得原文并保留定位后（§9.4.4）方可承载影响结论。**来源依据判据（round-7 收紧）**：事件段内**仅以标题/URL/链接为依据**的 `[来源:]` 绑定，以及**标签自述未读/未核/未取得/不存在/缺失**（如 `[来源: 公告原文未读取]`）的绑定，均**不构成 ≥C 证据**——此类行按证据不足处理；含「原文/正文/全文/披露文件」且不含缺失字样的绑定照常有效。该判据同样适用于事件段表行的行内来源。渲染器结构行（分类摘要导语、来源缺口占位）照常豁免。
- **证据等级行合法结构（R12 round-5）**：analysis.json 的 `evidence_tag` 在 schema 入口与此行采用同一完整语法，非法尾注须在渲染前拒绝。`**证据等级：** <等级 A-D / L1-L4>`，可选后缀为**四维齐全序列**（强度→来源→时效→交叉、图标-注解配对，同 §5.2 语法）；**半截序列/图标注解矛盾/词表外文字不豁免**——如 `**证据等级：** B ✅该标的有望走强`、`B 🕐 近 30 日` 仍按断言扫。
- **强度标签不是证据（R12 round-5）**：`[证据强度: …]` 只是元数据——仅当整行恰为合法四维标签（四维齐全、固定顺序、图标-注解配对；解析规则唯一来源 `skills/lib/evidence_tags.py`）时按结构行跳过；单维简式 `[证据强度: ⚠️ 中]` 不属合法四维标签（引擎已改出 `**证据强度：⚠️ 中**` 渲染器体例）；标签内夹带的文字/数字不是证据，标签外的断言仍须 `[来源:]` / `[证据: A-C]` / 真实 `[事实: F…]` 绑定，不得凭 ✅ 自授 ≥C。

### 5.4 阅读区写作规则（v0.3.1 阅读验收，2026-10-07）

> 适用于含「重要发现（5 分钟阅读区）」/`overview` 槽位的研究备忘录（stock full 默认载体）。
> **段数按证据量**——本规则不规定固定段数（某案例恰好为 5 段是其证据量使然，不是通则）；
> 「本次问题与数据截止 → 主判断 → 关键证据 → 竞争解释与边界 → 多情景前提 → 下一步核验」是**阅读路径**，
> 不是强制栏目。阅读预算沿用既有口径（首屏约 300–500 汉字，主阅读面 1,500–2,500 汉字；实测以机器篇幅层为准）。

1. **数据 → 事实逻辑 → 可追溯方法框架 → 有边界的分析结论**：方法框架必须可核验——引用已有方法文档的具体
   条目（如 [financial-semantics.md](financial-semantics.md) 的公式条、本文件 §6/§9）或**实际读过的原文**（给链接）；
   代理读数不得等同论文变量，不得声称复现论文、不得据单期读数断言失真/误定价/方向；不堆术语、不伪造引文，
   不以名词代替论证。
2. **短标题 + 少量关键事实**：段 `title` 为短判断句（D4），不复述段内全部数据；首屏只留判定所需的关键读数与前提；
   完整表（多情景多法九格、价格证据、历史样本等）放**正文现有宿主**（九模块/分析详情等），不在首屏重复罗列——
   不牺牲推理准确性与核验结构去保留数字重复。
3. **核验段 = 四问结构**：`问题 / 候选解释（非穷尽）/ 判别数据 / 观察节点`；并列读数须各自标注对象、期间与用途
   （不同对象的价位并列 ≠ 参与者对同一对象的判断分歧）；未取得一手原文的线索标「待核验、影响未知、不纳入结论」；
   二手或相互冲突的日期保留「待公告/原文确认」。
4. **口径与前提写实**：情景方法前提按引擎实际模型写（例：PB 倍数取历史 PB 中位数乘设定系数——中性不等于回到中枢；
   E-P 法含要求回报率与永续增长假设），不得用泛化「均值回归」代替；概率权重标「引擎设定假设（研究框架估计值，
   非统计频率）」；恒等式注明每股口径（**PE=股价/每股盈利（EPS）、PB=股价/每股净资产**），分位读数不单独推断中枢移动；
   现金流等读数不自动改动机械估值输入（是否修订须另验 EPS/每股净资产/倍数/r/g）。
5. **首屏不写开发返工记录**：报告直接给正确的事实、框架、分析与边界；「原写法不成立/最小降级」一类记录进实施交接
   与（必要时）附录说明。
6. **业务与产业位置写来源与边界**：写「公司靠什么赚钱」（主业/收入构成）须用封存收入分项数据 + `source_path`
   （如 `dimension_by_name.segments.data.<i>.sales`，单位换算显式）；行业分类/引擎行业映射只作**分类层面**的
   位置声明（如「通信设备产业链中游」），须明示不构成对公司竞争优势或定价权的验证；粗映射的上下游不得当作
   公司实际客户。
7. **同一主阅读面内去重**：同一读数/判断（如 PE/PB 历史位置）在同一主阅读面只出现一次、由其主段承担
   （PE/PB 历史位置归估值证据段），不在多段重复；首屏与正文底稿明细（现有宿主/分析详情）的重复不算首屏
   重复——关键事实允许从底稿引用，正文明细保留不当作首屏重复。

> **「旧明细迁移段」不是默认机制**：某次验收为保留旧首屏明细而临时启用的迁移段（`position=analysis` 的普通分析段，
> 经既有 `_render_analysis_appendix` 进底稿尾部）只解决该案例的保留问题；**一般要求**是完整数据/分析留在正文现有宿主，
> 不要求未来每篇复制全部旧首屏为迁移段，也不得据迁移段新增默认栏目或 schema。

```
…（按国内/海外分组逐行；读数/信号/来源/截至日期取封存原值）
```

- **保留全部原读数与信号**（国内段 + 海外段指标集），不增删指标、不引入新阈值；
  **币种/口径列须逐项准确**：指数（点）、同比百分比、人民币/美元利率百分比（**利率读数，非金额**）、
  人民币信贷金额、美元/桶、人民币元/美元（USDCNY 报价方向）——不得把指数或同比误标成币种金额。
- **条件边界随块输出**：宏观状态仅作外部背景锚定，不得自动推演为公司成本/盈利结论；
  海外结论中的候选线索短语（如「外部估值压制为候选线索，未经本报告验证」）为引擎确定性规则原文。
- **紧凑两段式标签**（`macro.macro_signal_label`）**合同不变**，仍用于 brief/concise 与
  invest-a-pulse 等既有消费者；`|` 为 ASCII 分隔符且条件出现（无海外指标时不得出现）——
  `tests/test_v015_fixes.py::TestMacroLabel` 锁定；海外段指标集由
  `tests/test_macro_extended.py::TestLabelE2` 锁定（基线信号不显示，避免冗长）。
- **两段结论均由确定性规则生成**（`macro._global_conclusion`、国内段政策方向判定），
  分组块与标签共用同一组结论函数（单点定义，避免两套口径）；不由 LLM 书写，
  海外规则输入是引擎已产出的 `signal` 字段。
- 溢出指标明细见报告附录「数据质量与引擎自检」。

**标签生成责任**（F2-7）：当前引擎自动生成宏观标签并写入报告头部。Claude 须核验标签数字为**最新期**（akshare PMI/CPI 序列最新在前，引擎曾取 2008-01 旧行，F0-4 已修）；发现非当期数字时按正确值改写标签并标注来源。

### 9.2 估值分位使用规则

1. **仅模块 1（当前状态快照）的"估值位置"段使用"分位"一词**；其余模块用"历史位置"或"区间位置"。
2. **亏损期标的强制标注**：PE 历史序列中 >30% 交易日为亏损期 → 分位旁标注"该标的历史大部分时间微利/亏损，PE 分位数仅作位置参考，不反映估值贵贱"。
   - **判据口径（v0.3.1 对齐实现）**：① 分位序列本身只取**正值**（亏损期不参与分位计算）；② **亏损期占比按「缺失/NaN 或 ≤0」的交易日计**——数据源（tushare `daily_basic`）把亏损期写成**缺失**而非负数，按"负数"判据会漏掉全部亏损期（中红医疗 300981 实测：1212 行中 687 行 `pe_ttm` 为 NaN = 56.68%，按旧表述得 0%）。实现见 `lib/valuation.py:106-108`、`html_charts.py:106-109`、`valuation_calc.py:893-902`；阈值 0.3 的判定在实现侧，三处同口径。
3. **分位数不单独使用**：必须伴随中位数或均值。✅ "PE 93.11x，近4年 98.3% 分位（中位数 37.52x）" ❌ "PE 处于历史 98.3% 分位"

### 9.3 估值口径与币种（C2-a，v0.3.1 收尾）

财务输入、公式前提和派生来源统一按 [财务语义与计算规范](financial-semantics.md) 执行；本节维护报告表达，不替代计算契约。特别区分实际历史 ERP 基准与当前模型 rf 的选择。

1. **每条估值路径必须写明币种、模型、rf 与来源、关键假设**：无风险利率标注格式为「中国 10Y 国债（akshare）/ 美债 10Y（FRED.DGS10）」——只写「10Y 国债收益率」不带币种不合规（反例：600519 `2026-10-02-22-32-48.final.md` 以美债 5.29% 作 A 股折现率且未标币种）。**ERP 序列标签绑定实际运算序列（2026-10-07 主线收尾）**：ERP 值/分位来自其自身对齐的 10Y 序列（`erp.y10_source`/`rf_currency`），与「当前 rf 现值闸门」（`resolve_rf` 的 cn10y 优先）是两条路径——两者并存时（如美元历史序列 + 独立人民币现值）ERP 行标签须写序列自身口径，人民币现值另行披露并注明「未参与本 ERP 计算」；美元序列不得标成中国国债口径。
2. **A 股折现/隐含增长率优先人民币口径**：rf 取 `market_structure.erp.cn10y`；仅美元口径可用时（旧快照或中国 10Y 不可得），引擎按「无风险利率口径不可用」暂停隐含增长率/方向解读/DCF 数值情景并显示缺口——不得以美债利率继续做 A 股方向性结论。
3. **不同 rf 币种或不同模型的估值路径是显式不同情景**：可以并列数值与算术差额，**不得**写「方向一致 / 共同指向同一市场预期 / 两者互为印证」；无法统一口径时不输出合并结论（反例：600519 L191「方向结论一致、幅度不稳健」）。
4. **跨币种比较**（如 E/P 与美债利率的利差）必须标注两侧币种与口径；换算口径不可得时不作利差解读。
5. **PCR/认沽认购比的表述边界**：它是成交量结构的位置描述与情绪代理参考，只能写「认沽认购比 X（分位 Y，窗口 Z，数据时点）」；**不得**表述为「为下行保护支付的价格 / 保费 / 溢价」或由比值推断期权定价含义（反例：600519 L179/L534）。
6. **隐含增长率 vs 历史 CAGR 的差额不裁决定价（REV-04，2026-10-07 主线收尾）**：`g_implied` 是简化永续模型读数，与实际 CAGR（有限历史区间）口径未统一（收益分配、风险、盈利与可分配现金流差异）——只列两数与差额并写明模型条件，**不得**写「市场定价偏乐观/偏悲观」「可能存在低估」或反之的方向裁决。

### 9.4 期间、对象与事件窗口（C2-d，v0.3.1 收尾）

期间转换、同比/环比/TTM、比率和每股指标的计算准入见 [财务语义与计算规范 §2–4](financial-semantics.md)。排序和去重不证明期间可比；逐值事实校验不证明比较关系成立。

1. **期间口径分离**：年度/半年/单季/TTM 分开陈述；只在可比口径下断言变化（单季对单季、中报对中报）；不得把年报与中报拼进同一「趋势」序列（反例：600519 L38/L46）。**累计期不得直接相减做环比（REV-01，2026-10-07 主线收尾）**：半年累计含一季度，相邻累计行相减等于跨期混比——环比须先按同财年相邻期拆分单季（Q2=H1−Q1）再比较，拆不出单季时退回同报告期同比（同 MMDD、上年），两者皆不可得则标方向不可得；修订重复行（同 end_date）先去重，禁止同一行自比（反例：600519 半年 445.17 亿 vs 一季度 272.43 亿曾直接判「净利润环比 ↑正向」；银行重复行自比得「→中性」）。**代理指标命名（REV-07 同批）**：ΔRevenue/CAPEX 类比值须用同报告期窗口（本期 vs 上年同期）计算，且只能称「营收增量/资本开支代理读数」，不得命名「研发回报/投资回报」或据此给出效率结论（研发投入明细未采集时如实披露）。
2. **对象标识**：行业/个股/基准分别标明；引用「行业排名/中位数」须给出口径与家数，不同口径的家数不得混用（反例：600519 L64 vs L827 的 8/10/9 家）。
3. **事件窗口分离**：事件生效/披露/业绩窗口三分；未来事件不得解释此前已发生的业绩或价格结果；机制不足时标「推测，待验证」，不用时间先后证因果（反例：600519 L144「时滞」、L114「主动收缩」）。
4. **外部关键事实**：须实际读取原文并保留定位（`notice-body` 等入口）；未取得原文时降级相应判断——检索摘要/二手转述（业绩说明会报道、外部研报）只能作线索句，不得承载结论或进入核心论证（反例：600519 L148/L991）。**事件类（R13，2026-10-05）**：公告标题、源类型分类与 taxonomy 类型默认维度/持续性是**分类线索**，不是已核影响——未读公告原文时不得断言治理/程序性事件「不影响盈利与估值」「不构成扰动」或给出任何影响方向/持续性结论，应写「影响未知/不纳入经营结论」；取得原文后结论须带原文定位。类型默认提示字段（`dimension_hint`/`duration_hint`）只作采集线索，渲染层须标注「类型默认」、不得直出为影响结论。
5. **档案一致性**：正文的风格/周期/焦点表述必须与封存档案（`.profile.json`）及引擎 `style_match` 一致；不得自评与档案矛盾（反例：600519 profile=价值 vs 正文自评「成长」，L329）。
6. **引擎自动多空链/风险叙述（R15，2026-10-05 round-7 / round-8）**：估值分位、相对涨跌、ROE/OCF 覆盖比、同行排名等均为**读数**——不得以「→」链条把它们断言为确定因果或操作指向：低 PE 分位不证明「市场已计入悲观预期/回归动力」；跑赢行业不证明「资金主动配置/未来相对优势」；ROE/PB/PE 的代数关系不能解释历史分位变化的唯一因果。引擎自动链与手写分析须改为「读数 + 待验证解释 + 反向解释 + 局限」，不得仅加 `[推测]` 标注而保留确定因果辩护；无依据传导应删除。数值原料（分位/读数）保留。**分式关系（round-8；2026-10-07 主线收尾收紧）**：静态恒等式 PE=价格/盈利、PB=价格/每股净资产——正盈利下修本身会**抬高** PE，不得写「低 PE 由盈利下修造成」；低 PE 陷阱的候选路径（在价格/盈利读数与比较窗口固定的前提下，**非穷尽**，如①价格调整更大/更快、②当前盈利处高点下修后 PE 回升）须写明条件并声明未穷尽；分位读数还依赖比较窗口与分布——「仍低」不等于「继续下降」，不得以「只能是」类穷尽句式收敛为非此即彼判断。低 PB 的盈利不是直接分母，其风险须区分**价格变化**与**对未来盈利能力/资产质量的预期**（净资产才是 PB 的分母侧）。**窗口读数（round-8）**：仅由「近 10 日累计净额」触发的资金流信号/链，标题与信号名只描述窗口读数（「近 10 日净流入/净流出」），不得外推为「持续流入/持续流出」；同类持续性/因果标题一并核查。
