# H4 预注册 — 黄金股金价 beta（冻结于回测前）

> 规格来源：ABCD §3.2 H4 行。改动须记 changelog 标注「探索性变体」。

## 假设
H0：黄金/有色个股对金价无显著 beta（β_gold = 0）。
H1：β_gold > 0 且显著；Baur (2014) 非对称：金价上涨期敞口 > 下跌期敞口。

## 数据与口径
- 个股：Tushare daily+adj_factor 前复权日线，2021-08-13 ~ 最新（5 年）
- 市场因子：000300.SH index_daily 同日收益
- 金价主因子：COMEX GC（akshare futures_foreign_hist 全历史）收盘收益，
  **T-1 对齐**（A 股收盘时 COMEX 未收盘，时区错配防护）
- 稳健性：沪金 AU0（futures_main_sina，2024-01 起）同日口径，子样本对照

## 检验
1. 每只股：ret_i ~ [mkt, gold]（ols_multi，NW HAC t）；ΔR² = R²(双因子) − R²(仅市场)
2. Baur 非对称：按金价月度方向分桶（当月金价收益 >0 为 up），up/down 两段各跑双因子回归
3. 池级汇总：β_gold 均值/中位数、显著比例

## 显著性判据
✅ 主检验 t≥3.0（NW）且 β>0；⚠️ 2.0≤t<3.0；❌ t<2.0。
池级结论 = 池内显著（t≥3）个股比例 + β 符号一致性。

## 稳健性清单
□ AU0 沪金替代 □ 仅市场模型对照 □ T-1 改同日（敏感度） □ 剔除 2024 前子样本

Tufano (1998) β≈2、Baur (2014) β≈1 的先验远大于最小可检出。
