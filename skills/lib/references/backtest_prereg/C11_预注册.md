## 假设

C11 的断言（源文档）：**「底部三特征模板：放量杀跌 → 缩量阴跌 → MACD 底背离；
反弹缩量回踩；涨停站上中期均线（右稳左可、必带止损）」**。

**文献边界（必须随结论标注）**：
- **整体形态无直接证据**；元素级相邻文献**部分支持**，但方向不一：
  - 涨停后一周**反转**的证据（Seasholes-Wu 2007 **上证 2001-2003**；Chen et al. **深交所账户级**）
    与「涨停确认续涨」**方向相反**，且**样本为早期**
  - 特征③的**条件分层假设**（连板数/换手/公告性质）出自 **Liu (2015)（中文期刊，待核验）**
    ——**不得作为框架依据**
- → 三特征**只作筛选特征**，须自家样本后验 + RC p；事件研究引用**须带样本期注记**，
  进规则层前须**当前市场滚动复核**

- **H0（原假设）**：三特征筛选出的标的，其前向收益与**无条件基线无差异**
- **H1（备择）**：存在显著差异（**不预设方向**——反转与延续两种文献预期并存）
- **R-B02 子假设**：左侧（未确认底背离）与右侧（突破确认）两组的胜率/超额/回撤**无差异**

## 样本（写死）

**池**：沪深主板 + 创业板 + 科创板；剔 ST/退市/北交所；K 线 ≥ `MIN_BARS=120`
**样本期（写死）**：2018-01-01 ~ 2026-08-31（覆盖两轮风格切换）
**数据**：tushare `daily` + `adj_factor` 前复权自算（沿用 pattern-scan 既有口径）
**窗口**：前 120 日形态 + 后 5/10/20 日前向

## 事件定义（**参数表写死**，见 `feature_patterns.py` docstring）

| 特征 | 关键定义 | 默认参数 |
|---|---|---|
| ① MACD 底背离 | 相邻两个**可确认 pivot 低点**满足 `price 更低 ∧ DIF 更高` | MACD 12/26/9；pivot_window 10；max_pivots 4 |
| ② 缩量回踩 | 自前高回踩 ≥ 阈值 ∧ 回踩期量能 ≤ 峰值期量能 × 阈值 | peak_window 20；pullback ≥5%；shrink ≤0.7 |
| ③ 涨停站上 MA | 当日涨幅 ≥ 阈值 ∧ 收盘 > MA60 | limit_up_pct 9.8（**主板口径**）；ma 60 |

⚠️ **口径警告**：`limit_up_pct=9.8` 为**主板**口径；创业板/科创板 **20%**、ST **5%**
须在调用侧分流或显式标注，**混用会把 10%+ 的创业板正常波动当成涨停**。
⚠️ **pivot 固有滞后**：可确认 pivot 需左右各 N 根 → 最后一个低点**永远无法参与判定**
（这是**确认型**指标的属性，不是缺陷；但结论不得表述为「实时捕捉底背离」）。

## 检验

1. **RC p（决定性）**：三特征 × 3 窗口 = **9 条新规则**并入既有规则宇宙
   （2 形态 × 3 带宽 × 3 窗口 = 18）→ **共 27 条**，整体跑 `multiple_testing.reality_check`
   （White 2000 centered block bootstrap，`n_boot=5000, seed=42`）；
   **禁止**对单条规则单独看 p 值后宣称显著（那是数据窥探）
2. **左右侧双组回测（R-B02）**：突破确认组 vs 未确认底背离组，**同池同窗** →
   胜率 / 超额 / 最大回撤对照；措辞固定为「本池样本内右侧 X% vs 左侧 Y%，样本 N」，
   **禁止预设结论**
3. **滚动分段（强制）**：2018-2020 / 2021-2023 / 2024-2026 三段分别报告；
   **禁止全样本一次性结论**
4. **样本期注记**：引用 S&W / Chen 时须写明 2001-2003 / 深交所账户级 与
   A 股 T+1、涨跌停制度的差异

## 显著性判据

- ✅ RC p < 0.05 **且**三段同号；⚠️ RC p 0.05–0.10 或段间翻号；❌ RC p ≥ 0.10
- **双组差异**：|t| ≥ 3.0（NW HAC）且分段同号方作参考
- **分档判定**：只有 ✅ 才考虑把某特征提升为筛选条件；⚠️/❌ 则停留在**观察层**（当前状态）

## 稳健性清单

□ 换带宽（0.3/0.5/1.0）□ 换窗口（5/10/20）□ 剔一字板 □ 剔停牌 □ 剔 ST

□ pivot_window / max_pivots 敏感性 □ 涨停阈值按板块分流

## 功效

待验证时按实际样本量回填。事前说明：底背离年频次约 10³ 量级、涨停约 10⁴ 量级
（全 A）→ 主检验样本充足；但**27 条规则的联合 RC 会显著抬高单条规则的显著性门槛**
（这正是 RC 的用途）——预期多数单条规则**无法通过**，这是**预期结果而非失败**。
