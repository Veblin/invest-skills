# H2 预注册 — 大跌 ≥10% 低吸（冻结于回测前）

> 规格来源：ABCD §3.2 H2 行。改动须记 changelog 标注「探索性变体」。

## 假设
H0：大跌 ≥10% 后 +1/+3/+5 日市场调整超额为零（低吸无正期望）。
H1：可成交子集（开板/未触及）存在正超额。

## 样本（写死）
- 全市场：market_daily（Tushare pro.daily）2021-01-01 起全部 A 股
- 事件：pct_chg ≤ -10%（单日收盘相对前收）
- 分层（成交假设双口径）：
  - 封死（close ≤ limit_price，一字跌停不可成交）
  - 开板（low ≤ limit_price < close，盘中触停后打开，可成交）
  - 未触及（low > limit_price，暴跌未触停）
  - limit_price = round(pre_close × (1 − limit_pct), 2)；
    limit_pct: 主板 0.10 / 300·301·688 前缀 0.20（注册制 2020-08 后）
- 可成交子集 = 开板 + 未触及；全事件口径单独报告
- 板块对照：THS 商业航天板块指数（309130）大跌日同窗口表现（概念成分待东财恢复后补）

## 检验
1. 市场调整超额：事件 T+N 收盘收益 − 同日全 A 等权 T+N 收益（market_daily 自算）
2. 每层 × {+1,+3,+5}：NW t（hac_t_stats 截距）+ bootstrap_ci + 胜率/中位数（describe）
3. 事件聚类防护：calendar-time（同日多事件按日均值聚合）双口径
4. 幸存者偏差注记：pro.daily 无退市股，报告注明口径

## 显著性判据
✅ t≥3.0；⚠️ 2.0≤t<3.0；❌ t<2.0。ABCD 预期 ⚠️ 弱-中。
