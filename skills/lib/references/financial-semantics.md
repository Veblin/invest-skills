# 财务语义与计算规范

> **唯一维护位置**：本文件定义跨 Skill 的财务计算口径、公式前提与解释边界，随共享 references 分发。来源接口见 [data-interface-map.md](data-interface-map.md)，报告表达见 [report-conventions.md](report-conventions.md)，交付检查见 [delivery-qc.md](delivery-qc.md)。其他文件引用本规范，不另立同名指标的不同默认定义。
> 修订：2026-10-05。**规范建立不等于实现达标**：既有计算、侧车与 QC 须逐项迁移并验收；未覆盖的规则由人工复检明确记录，不能宣称机器已拦截。

## 1. 适用范围与依据

本规范约束财务数据进入计算、评分、模型和报告的方式；已有入口按实际使用指标适用，不要求 ETF、扫描等入口补采未使用的财报。A 股、港股共用语义原则，保留各自会计制度、会计年度和行业差异。

- 会计事实按企业适用的会计准则与实际披露读取。中期的资产负债表时点、利润表期间和累计现金流不得互换；依据 [财政部《企业会计准则第32号》第五条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46249.htm)，另见 [财政部季报现金流口径答复](https://www.mof.gov.cn/bd/mhwzzxly/hjs/202301/t20230129_3864201.htm)。
- 每股收益和披露 ROE 保留法定定义；依据 [证监会编报规则第9号](https://www.csrc.gov.cn/csrc/c101864/c1024649/content.shtml)。每股收益的分母须考虑加权平均股数；港股采用 IFRS 时参见 [IAS 33](https://www.ifrs.org/issued-standards/list-of-standards/ias-33-earnings-per-share.html/)。
- TTM、增长率、估值模型和代理评分是研究计算或项目约定，不冒充会计准则规定。公式名称相同但定义不同的，须分别标识，不静默选边。

## 2. 每个输入必须知道什么（FS-01）

下表是计算所需的**逻辑契约**，不是声称当前 JSON 已有这些字段。已有字段可映射；未知项只阻断依赖它的运算，保留可直接引用的事实。

| 信息 | 要求 |
|---|---|
| 对象与范围 | 公司/行业/基准；合并/母公司；总净利润/归母/扣非；普通股/全部权益；明确指标名称 |
| 期间与时点 | 会计年度起止、事实期间起止或余额时点；累计/单季/年度/TTM；报告期不以采集时间替代 |
| 已知时间 | 披露日期、修订版本、研究基准日；封存/前瞻复验不得使用基准日之后才披露的数值 |
| 数值与量纲 | 币种、元/万元/亿元、股数单位、百分数/小数/百分点；换算有明确系数 |
| 来源与状态 | 来源字段/原文定位、原始值、缺失或冲突原因；缺失与零值分开；拒绝 NaN/Inf/布尔冒充数值 |
| 派生过程 | 公式标识、输入身份、参数假设、输出单位、实际窗口、精度；标签继承实际运算来源 |

同一报告期只在**指标、对象、范围和口径相同**时处理重复披露。修订选择不得仅按日期无条件覆盖：先确认来源身份和可比重述；按研究基准日选当时可得版本，或明确事后重述口径。不能把不同来源/合并范围的同日记录当作重复。

## 3. 期间转换与比较

### FS-02：先分类，再运算

| 类型 | 例子 | 允许的期间处理 |
|---|---|---|
| 期间流量 | 收入、利润、经营现金流、资本支出现金额 | 确认同一范围且可加后，累计拆分/合计/TTM |
| 时点存量 | 总资产、净资产、应收、存货、期末股数 | 时点差或明确的期间平均；不得四季求和当作 TTM 余额 |
| 比率 | 毛利率、ROE、资产周转率 | 用相应分子分母重算或引用披露值；不得把累计比率相减当单季比率 |
| 每股指标 | 基本/稀释 EPS、每股现金流 | 确认利润口径和股数/复权基础；不得默认等同可加流量 |
| 条件模型/代理 | ROIC 近似、E/P 模型、评分 | 单列方法和假设；不能改名成会计事实或真实投资回报 |

### FS-03：累计拆单季

仅对同一会计年度、同一累计起点、相容披露范围的可加流量 X：

```text
Q1 = YTD_Q1
Q2 = YTD_H1 - YTD_Q1
Q3 = YTD_9M - YTD_H1
Q4 = FY - YTD_9M
```

缺任一必要输入就停止该单季运算，不以最近一行、零值或估计填补。季节性不改变公式，但限制环比解释。非日历年度按企业会计年度处理，不硬编码所有公司年末为 12 月 31 日。

### FS-04：TTM

对可加流量，采用完整连续四个单季合计，或相容范围下：

```text
TTM_X = 上一完整年度_X + 本年同截止期YTD_X - 上年同截止期YTD_X
```

记录完整覆盖起止、最新有效期、缺期和重述口径。两种合法重建路径应在数值精度内一致；不同输入版本不得强求一致。半年值乘二、最新季乘四属于年化假设，必须单列，不命名为 TTM。EPS、ROE 等不得直接套用流量公式。

### FS-05：变化与增长

```text
同比/环比增长率 = (本期值 / 可比基期值 - 1) × 100%
CAGR = ((终值 / 起值)^(1/n) - 1) × 100%，n 为实际年度间隔
百分点变化 = 本期百分数 - 基期百分数
```

增长率默认要求基期为正；零/负基期披露金额变化、扭亏或亏损扩大/收窄，不默认给常规增长百分比。CAGR 默认起终值为正且 n>0。同比配同会计期间、同累计属性；环比配相邻单季。累计值之间的差不能直接冠名环比增长。不同范围或无法确定比较窗口时不给方向。

## 4. 常用指标的定义与边界

| 标识 | 指标与公式 | 输入要求、失败处理及解释边界 |
|---|---|---|
| FS-06 | 毛利率=(营业收入−营业成本)/营业收入；净利率=指定净利润/对应收入 | 同期间、币种、合并范围；声明净利润是总额、归母还是扣非。营业收入不与营业总收入默认为同一字段；金融业无适用成本口径时不硬算制造业毛利率 |
| FS-07 | OCF 覆盖比=同期间经营现金流/指定净利润 | 指明利润口径。合并 OCF 与归母利润的组合须标明范围差异、只作代理覆盖关系；优先使用语义匹配的金额重算。利润≤0不沿用正利润覆盖评分；覆盖高不证明质量、持续性或可分配现金充足 |
| FS-08 | 简单平均权益 ROE 代理=期间归母利润/平均归母权益 | 平均方式需声明；期初期末平均只是近似，不能冒充披露的加权平均 ROE。披露 ROE 按来源定义引用；年度对年度或同中期对同中期；不能累计相减或无说明年化 |
| FS-09 | 基本 EPS=归属于普通股股东的期间利润/该期间加权平均普通股数 | 基本/稀释、股本变化、拆并股及重述须区分。缺股数口径不能累计 EPS 作差/直接滚动求和。每股现金流/EPS 作为金额覆盖比的替代，须证明股数基础一致 |
| FS-10 | 资产周转率=期间对应收入/平均总资产；杜邦分解采用一致范围的净利率×周转率×权益乘数 | 三因子须共享利润/收入/资产/权益和平均方式，才可作同一 ROE 的分解。混用来源比率只作近似，不能标为恒等式验算；低周转不直接证明重资产或经营恶化 |
| FS-11 | ROIC=定义明确的税后经营利润/对应平均投入资本 | NOPAT、税率、经营资产/负债及平均方式必须明确；总资产−流动负债等简化分母须标为代理。ROE 不充当未披露的 ROIC；金融业不直接套非金融企业口径 |
| FS-12 | 现金流代理 FCF=OCF−CAPEX；企业现金流模型 FCFF=NOPAT+非现金折旧摊销−CAPEX−经营营运资本增加 | CAPEX 明确是否购建长期资产现金支出、是否净额，规范为支出正额；不得盲目 abs 掩盖符号。OCF−CAPEX 不自动等于 FCFF/FCFE；银行等不适用时停止通用模型 |
| FS-13 | ΔRevenue/CAPEX 等评分代理 | 明确营收差的可比窗口、CAPEX窗口、阈值依据、缺失项和聚合分母；不命名为研发回报或经济投资收益率。不能依一个代理把管理层能力判定为事实；阈值属项目经验约定，不属会计标准 |

缺失原料时可以保留明确命名的合法代理，必须单列假设和局限；不能为评分完整填默认税率/虚构研发额等输入。评分输入降级后，相关子项、总分和报告解释须同步重新验收。

## 5. 估值与利率

### FS-14：PE、PB、E/P

```text
PE = 股价 / 口径明确的EPS
PB = 股价 / 对应每股净资产
E/P = 1/PE
```

股价时点、股本基础、EPS 的 TTM/年度/预测属性、权益归属须说明。源供应商的 TTM PE 保留其定义，不强行与另一个每股口径拼成恒等式。PE≤0不作正盈利估值解释；分位同时绑定样本范围、有效/缺失规则和算法。位置不能唯一反推预期、低估或均值回归。

### FS-15：ERP 历史与折现率假设分开

```text
历史指数E/P减国债读数（百分点）=100/同日指数PE−已对齐国债收益率百分数
模型要求回报率 r = rf + ERP_assumption（均用小数）
```

前者是特定基准下的研究读数，后者是模型假设，不能互换。历史值/分位绑定实际国债序列的币种、来源、日期对齐与回填规则；加入另一条现值不能重标历史来源。A 股人民币模型需要可用人民币 rf，USD 历史读数须明确错配并停止 A 股方向解释。0/负利率不自动视作缺失。

### FS-16：情景公式与逆向解释

```text
P_PE = EPS_scenario × PE_scenario
P_PB = BVPS_scenario × PB_scenario
简化E/P模型：P_EY ≈ EPS_assumed/(r−g)，需 r>g
该简化模型的代数读数：g* ≈ r−1/PE
```

逐法列清 EPS/BVPS、倍数、r、g、币种、时点和概率性质。简化 E/P 关系不是自动成立的真实市场模型：盈利与可分配现金流、派息/再投资、增长与盈利期次等假设必须声明，不能仅给模型名字。以 TTM PE 套用时明确其近似性质。

历史营收 CAGR 不是预期永续盈利增长；差额不自动裁决偏悲观/低估。多法组成的范围不能唯一逆推出市场盈利路径。逆向解释须固定模型与其他参数，实际求解并披露可识别性和敏感性；未做则停在价格位置与条件模型读数。

## 6. 计算结果与消费契约（FS-17）

引擎负责口径选择、运算与派生来源；渲染器展示已绑定结果，不能重新挑来源标签、重命名模型为事实或自行补方向。分析注入也遵守同一输入契约。最低可核记录包含：公式标识、输入路径/身份、对象/范围、期间/币种/单位、参数、结果、精度和降级原因。

内部计算保留有效精度，只在显示层舍入；复算按输入/显示精度设容差。数值与精度接近零时不得任意翻转方向。失败返回该指标的信息不足/不适用及原因，不影响其他有效维度，不用空值填零或旧值覆盖。

修改计算、来源或期间协议时，适用的生产者、评分、MD/HTML、分析侧车与检查器共同验收；签认绑定当前输入、源码和产物。具体正反例与交付责任见 [delivery-qc.md §7](delivery-qc.md#7-财务语义与反例回归)。

## 7. 规范的维护方式

每项新增/调整指标先确定定义、来源、前提、行业例外、失败行为和可观察反例，再修改实现；同名不同方法单列，禁止用一套默认公式遮盖合法口径差异。接口变化更新数据映射；本文件维护语义，避免再次散落公式副本。未覆盖指标登记为未验，不因本文件存在认定完成。
