# invest-a-event-calendar 限售解禁压力日历

> **工具约束说明**：frontmatter 的 `allowed-tools` 是 Claude Code 约定；在 DSH 等不读取该字段的 harness 下不生效，实际可用工具由平台自身沙箱控制。本技能全部操作为本地数据采集与计算（Bash/Python 引擎）。

## 概述

全市场解禁日历（东财限售股解禁汇总）：回看近 120 日 + 展望未来 30 日，逐日输出：

- 解禁家数 / 解禁数量（亿股）/ 实际解禁市值（亿元）
- **压力标注**：未来解禁日按市值相对近 120 日序列分位 — >80% = 🟠 高压日，>90% = 🔴 极高压力日
- 回看段附带当日沪深300 涨跌幅（观察解禁日市场表现，非因果断言）

**v1 边界（如实标注）**：全市场日历型接口只有解禁；股东户数/高管持股/分红实施日历均为**按股票**接口，需「自选/持仓池」才能成日历——v2 待池子机制（journal 持仓导出或清单文件，与 app 定时任务方向衔接）。

**解禁 ≠ 减持**：解禁是供给事件提示，非方向信号。控股股东/实际控制人解禁后多数不立即减持（锁定期另有承诺）；真减持需看减持预披露公告（invest-a-stock 公告采集已有）。压力日的作用 = 提示「该日前后相关个股的供给面事件集中度」，配合减持公告与 journal 评估使用。

## 运行

```bash
cd "${INVEST_SKILLS_ROOT:-.}" && uv run python skills/invest-a-event-calendar/scripts/unlock_calendar.py
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `--days-past` | 120 | 分位回看窗口（自然日） |
| `--days-future` | 30 | 展望窗口（自然日） |
| `--no-out` | false | 不落盘 |
| `--out-dir` | `reports/event-calendar/` | 输出目录 |

落盘：`reports/event-calendar/{YYYY-MM-DD}.md`

## 数据源与口径

- 接口：`stock_restricted_release_summary_em(symbol="全部股票")`（东财数据中心；代理环境可能 ProxyError → 输出「数据不可得」退出码 3，不硬编）
- 原始单位：解禁数量 = 股、实际解禁市值 = 元（脚本换算为亿）
- 汇总口径缺行日期 = 当日无解禁（东财页面语义）
- 分位 = bisect_left 口径（同 pulse），基准 = 近 120 日**有解禁日**的市值序列

## 分析纪律

1. **解禁 ≠ 必然减持**：压力日只提示事件集中度；个股层面须查减持预披露（若大股东计划减持会先公告）——压力日 + 减持公告双信号才构成供给面关注（仍非买卖信号）
2. **分位是横向提示**：市值分位高 ≠ 利空成立——需看解禁股东类型（控股 vs 财务投资者）与当前股价位置，本工具只给日历与分位
3. **不要用回看段的沪深300表现做因果**：那是参考坐标，不是「解禁日必跌」的证据（样本与混杂因素未控制）
4. **数据不可得时如实降级**：东财 ProxyError → 明确标注「解禁日历数据不可得」，不以旧数据充数
