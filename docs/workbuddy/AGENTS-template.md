# 用户级 `~/.workbuddy/AGENTS.md` 模板

> 用途：WorkBuddy 用户级项目指令（对应 Claude Code 的 `~/.claude/CLAUDE.md` 层）。
> 复制以下内容到 `~/.workbuddy/AGENTS.md`（macOS）或 `%USERPROFILE%\.workbuddy\AGENTS.md`（Windows），
> 替换 `<repo 绝对路径>`。5 条硬约束为投资合规红线，措辞规范摘要为输出质量底线。
> 完整规范见本仓库 `skills/lib/references/report-conventions.md`（canonical 源）。

```markdown
# AGENTS.md — invest-skills（WorkBuddy 用户级）

> 项目仓库：`<repo 绝对路径>`（设 `INVEST_SKILLS_ROOT=<repo 绝对路径>`，
> macOS 写 ~/.zshrc；Windows 设用户级环境变量并完全重启客户端）

## 五条硬约束

### 约束 1：禁止荐股（LAW 6）

不输出任何形式的"买入/卖出/持有"建议、仓位建议。允许多情景估值参考价，
但必须标注假设前提、概率权重，并明确"仅供参考，不构成投资建议"；
不允许无假设前提的单一目标价数字。这是法律红线，也是能力边界。

### 约束 2：LLM 不可作为投资决策的主要信源

AI 输出只能作为"学习材料的整理和解读"，不能作为"投资决策的依据"。
关键财务数据必须标注原始来源（财报 PDF / akshare / Tushare），让用户能追溯验证。

### 约束 3：所有分析解释必须依赖数据源，引用来源

每个论述要么标注数据来源，要么明确声明为"待验证的推测"。
没有数据支撑的分析不输出；引擎没有的字段写「未知/不可得」，不推断。

### 约束 4：事实边界（三态标注）

「检索不到」不得断言「数据不存在」，只允许「公开不可独立验证」；
数据冲突并列报告不自行裁决；无法核实的数字标注三态（可验证 / 公开不可独立验证 / 未知）。

### 约束 5：引擎命令统一带 cd 前缀

所有引擎调用必须写 `cd "${INVEST_SKILLS_ROOT:-.}" && uv run python ...`
（或 `cd "${INVEST_SKILLS_ROOT:-.}/skills/invest-a-journal/scripts/lib" && uv run python -c "..."`），
禁止裸 `uv run python` 调用。

## 措辞规范摘要（完整版见 report-conventions.md）

1. **P0 数字引擎计算**：AI 禁止心算任何数值（加减乘除/百分比/均值/分位/计数）。
   所有数字引用引擎字段或标注 `[来源: Python calc: formula]`。
2. **分析标记**：每个分析段落先 **[事实]** 块（引用来源）→ 再 **[分析]** 块（逻辑推演），
   [分析] 块末尾附四维证据标签：`[证据强度: ✅/⚠️/❓ 强/中/弱 🌐/📡/🔮 多源/单源/推测 🕐/📅/🗄️ 时效 ✓✓/✓✗/— 交叉验证]`
3. **禁止词替换表（摘要）**：
   - "估值崩溃风险" → "剧烈估值收缩风险：在 XXX 场景下，估值从 AAAx 收敛至 BBBx"
   - "极度高估/低估" → 数值比较（"PE 665x vs 同赛道平均 40x，溢价约 16 倍"）
   - "崩盘" → "剧烈回调"（后接条件描述）
   - "往往是估值峰值" → "盈利峰值与估值峰值出现时间高度重叠（案例：XXX），但并非必然规律"
   - 无来源的"往往/通常"必须标注「待补」或转为案例
4. **估值分位使用规则**：
   - 仅「当前状态快照」模块用"分位"一词，其余用"历史位置/区间位置"
   - 每个分位数字必须伴随对应中位数或均值（"PE 93.11x，近4年 98.3% 分位（中位数 37.52x）"）
   - 亏损期标的（>30% 交易日亏损）：分位数旁标注"仅作位置参考，不反映估值贵贱"
5. **报告复检**：发出简报前三层复检——① 数字复检（对照引擎 JSON/Python calc 输出）
   ② 合规复检（无买卖建议/无 AI 心算/禁止词/事实边界/证据标签）③ 逻辑复检（判断与数据自洽、
   对抗性假设 ≥3 且可证伪、盲点 ≥2）。

## 运行命令速查

见 `~/.workbuddy/memory/MEMORY.md`（或本仓库 docs/cli.md）。
```
